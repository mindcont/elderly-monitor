可以把这个项目设计成一个比较标准的**边缘 AI 老人检测网关**：Ubuntu 上运行 Qt 应用，RTSP 摄像头提供视频流，YOLO11 负责人员检测，再通过 MQTT 发布事件，Home Assistant 后续订阅并联动。

我建议第一版**不要直接做“老人识别”**，而是做成“人员检测 + 区域/时间规则 + MQTT 事件”的架构。后续如果需要区分老人、家人、护理人员，再增加人体属性、ReID 或专门分类模型。

# 三、RTSP 视频模块

建议不要让 Qt 自己承担 RTSP 解码。

采用：

```text
RTSP
 ↓
GStreamer / FFmpeg
 ↓
Decoded Frame
 ↓
OpenCV / CUDA
 ↓
YOLO11
```

Ubuntu 下建议优先：

**GStreamer**

尤其如果以后运行在 NVIDIA Jetson 上，可以直接利用硬件解码。

例如：

```text
rtsp://user:password@192.168.1.100:554/stream1
```

统一封装：

```cpp
class RtspCamera
{
public:

    bool Open(const QString& url);

    bool Start();

    void Stop();

signals:

    void FrameReady(const QImage& image);

    void Error(const QString& message);
};
```

但实际项目中建议不要直接：

```text
RTSP → QImage
```

而是：

```text
RTSP
 ↓
AVFrame / GstBuffer
 ↓
cv::Mat / GPU Tensor
 ↓
YOLO
 ↓
QImage
```

避免大量 CPU 内存复制。

# 四、YOLO11 检测

第一版直接使用：

```text
YOLO11n
```

原因是老人家庭场景通常并不需要特别大的模型。

模型：

```text
yolo11n.pt
```

检测：

```text
person
```

输出：

```cpp
struct Detection
{
    int classId;

    float confidence;

    QRectF bbox;

    int trackId;
};
```

例如：

```json
{
    "class": "person",
    "confidence": 0.93,
    "bbox": [532, 180, 712, 650]
}
```

# 五、为什么建议加入 Tracking

仅仅：

```text
YOLO
 ↓
发现 person
 ↓
MQTT
```

会产生大量重复消息。

例如老人站在客厅：

```text
Frame 1 → person
Frame 2 → person
Frame 3 → person
Frame 4 → person
...
```

如果每一帧都 MQTT：

```text
person_detected
person_detected
person_detected
person_detected
```

没有意义。

所以建议：

```text
YOLO11
   ↓
ByteTrack
   ↓
Track ID
```

例如：

```text
老人
Track ID = 7
```

持续：

```text
Frame 100 → ID 7
Frame 101 → ID 7
Frame 102 → ID 7
Frame 103 → ID 7
```

这样事件系统才能判断：

```text
进入
离开
停留
长时间未移动
```

# 六、“老人检测”建议分成两阶段

这里是整个系统最值得设计好的地方。

YOLO11 默认只能告诉你：

```text
这是 person
```

它**不能可靠地仅凭普通 COCO `person` 类直接判断“老人”**。

因此建议第一阶段定义为：

> **老人活动检测系统**

而不是：

> 老人身份识别系统

例如：

```text
摄像头
 ↓
Person Detection
 ↓
Person Tracking
 ↓
区域判断
 ↓
时间规则
 ↓
老人活动事件
```

如果摄像头是专门安装在老人居住环境中的，那么：

```text
检测到 person
```

可以在业务层解释为：

```text
老人出现
```

这样第一版就非常容易落地。

# 七、区域检测

建议加入 ROI。

例如客厅：

```text
┌───────────────────────────────┐
│                               │
│        客厅 ROI               │
│                               │
│        ┌──────┐               │
│        │ 老人 │               │
│        └──────┘               │
│                               │
│                 厨房          │
│                               │
└───────────────────────────────┘
```

配置：

```json
{
    "name": "living_room",
    "polygon": [
        [100,100],
        [1200,100],
        [1200,700],
        [100,700]
    ]
}
```

然后判断：

```cpp
bool IsInsideRoi(const QRectF& personBox);
```

# 八、事件引擎

不要把业务逻辑直接写进 YOLO 模块。

单独建立：

```cpp
class EventEngine
{
public:

    void Process(
        const QList<Detection>& detections,
        const QDateTime& timestamp);

signals:

    void EventGenerated(const DetectionEvent& event);
};
```

例如：

### 事件1：老人出现

```text
person
 ↓
进入 ROI
 ↓
持续 N 帧
 ↓
老人出现
```

MQTT：

```json
{
    "event": "elderly_detected",
    "camera": "living_room",
    "track_id": 7,
    "confidence": 0.94,
    "timestamp": "2026-09-21T16:30:15+08:00"
}
```

# 十、长时间未活动

这是后面真正有价值的功能。

例如：

```text
老人进入客厅
       ↓
持续检测
       ↓
长时间没有位置变化
       ↓
触发异常事件
```

例如：

```text
30 min 无明显移动
```

产生：

```json
{
    "event": "elderly_inactive",
    "camera": "living_room",
    "duration": 1800,
    "timestamp": "2026-09-21T17:00:00+08:00"
}
```

但这里需要注意：

**“没有移动”不能直接等价于“跌倒/危险”。**

所以建议后续增加：

```text
YOLO11-Pose
      ↓
人体关键点
      ↓
姿态分析
      ↓
Fall Detection
```

# 十一、MQTT设计

MQTT Topic 建议从第一版就规范起来。

例如：

```text
home/ai/camera/living_room/event
```

或者：

```text
home/elderly/living_room/event
```

推荐：

```text
home/ai/{camera_id}/event
```

例如：

```text
home/ai/living_room/event
home/ai/bedroom/event
home/ai/entrance/event
```

# 十五、Qt线程设计

这一点非常重要。

**千万不要在 Qt UI 线程里面直接跑 RTSP + YOLO。**

建议：

```text
                    Main Thread
                         │
                     Qt UI
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        ▼                ▼                ▼
 Camera Thread      AI Thread       MQTT Thread
        │                │                │
      RTSP             YOLO            MQTT
        │                │                │
        └────── Frame ──▶│                │
                         │                │
                         └── Event ──────▶│
```

Qt：

```cpp
QThread
QObject::moveToThread()
```

实现。
